常见问题

需要什么样的地图？

等距经纬度投影的高程图(PNG/TIFF/GeoTIFF)、带色带的分层设色地形图，或用几种颜色画出海、河、山的草图。填写地图的经纬度范围即可，南北半球都支持。

结果准确吗？

气候与资源由概念模型推算，适合创作与教学；大尺度规律(气候带、季风、雨影、沙漠)可信，局部数值仅供参考。历史演化是带随机性的模拟，同样的参数与随机种子总是得到同样的历史。

我上传的地图和生成的结果归谁？

归你所有。我们只为提供服务而存储与处理它们，你可以随时删除。详见服务条款与隐私政策。

可以用在商业项目里吗？

可以。导出的数据与图片可以用于你的游戏、书籍或其他作品。
